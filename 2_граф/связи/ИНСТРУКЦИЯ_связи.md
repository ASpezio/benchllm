# Связи между понятиями (проект «SyllaBench», часть «Граф»)

Вход — JSON с полем `concepts`: понятия школьной программы одного предмета, упорядоченные по месту первого появления в программе (`order`: 1 — раньше всех; `first` — класс, код и текст элемента, где понятие появилось впервые; `elements` — все элементы, где оно встречается; иногда `formulas`, `aliases`).

Задача — проставить связи между понятиями **из этого списка**. Это основа для поиска знаний и для вопросов «что нужно знать, чтобы понять X».

## Типы связей

| type | направление | смысл | примеры |
|---|---|---|---|
| `prerequisites_for` | A → B | чтобы понять B, нужно уже знать A (прямая предпосылка) | Масса → Плотность; Сила → Давление; Площадь опоры → Давление твёрдого тела; Персидская держава → Греко-персидские войны; Карфаген → Пунические войны |
| `is_a` | A → B | A — вид / частный случай B | Конвекция → Теплопередача; Сила трения → Сила; Полис → Город-государство |
| `part_of` | A → B | A — часть, эпизод, составная часть B | Марафонская битва → Греко-персидские войны; Иероглиф → Письменность (если иероглиф — часть письменности) |
| `participant_of` | A → B | только история: личность A действовала в событии / процессе / государстве B | Ксеркс → Греко-персидские войны; Хаммурапи → Древний Вавилон |
| `verifies` | A → B | только физика: опыт A подтверждает, демонстрирует или измеряет закон / явление / величину B | Измерение плотности жидкости → Плотность; Опыт Торричелли → Атмосферное давление |

## Правила

1. Оба конца — `id` из входного списка. Никаких новых понятий.
2. **`prerequisites_for` — только прямые предпосылки.** Если A → B и B → C, не ставь A → C. Не ставь связь «на всякий случай»: только если без A действительно нельзя понять B (в определении B используется A, или событие B невозможно объяснить без A).
3. Порядок: предпосылка обычно появляется раньше (`order` меньше) или в том же элементе. Если по смыслу предпосылка нужна, а в программе она появляется позже, всё равно поставь связь и добавь `"order_issue": true` — это важная находка.
4. Не ставь `prerequisites_for` между двумя понятиями, если между ними `is_a` или `part_of` (вид не является предпосылкой рода и наоборот — достаточно одной связи).
5. Для каждой связи — короткое объяснение `why` по-русски (до 15 слов).
6. Ориентир по количеству: в среднем 1–3 связи на понятие; у понятий-«листьев» (конкретные опыты, приборы, памятники) может быть одна связь, у базовых (масса, сила, государство) — много исходящих.
7. В истории `prerequisites_for` — это не хронология «раньше — позже», а «нужно знать, чтобы понять»: участники, предпосылки, причины, место действия.

```json
[{"source": "C.physics.massa", "target": "C.physics.plotnost-veschestva", "type": "prerequisites_for", "why": "плотность определяется через массу и объём"}]
```
