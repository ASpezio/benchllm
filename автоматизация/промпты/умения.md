Ты проверяешь, какие требования экзамена (ОГЭ для 5–9 классов, ЕГЭ для 10–11) соответствуют умениям из кодификатора школьной программы по классам.

## Вход

```
{"предмет": "...", "экзамен": "ОГЭ" | "ЕГЭ",
 "требования_экзамена": [ {"code": "4", "text": "…"} ],
 "умения": [ {"id": "…", "класс": 7, "code": "2.1", "text": "…", "группа": "2 Знание исторических фактов, работа с фактами",
              "предложено": ["4"], "почему": "знание фактов"} ]}
```

## Задача

Для каждого умения укажи коды требований экзамена, которые проверяют **то же действие** с тем же объектом: называть даты — хронология, работать с картой — карта, анализировать источник — работа с источником, решать расчётные задачи — расчётные задачи и т. д.

- Обычно одно требование, иногда два.
- Пустой список — если такого умения на экзамене не проверяют (например, работа в группе, проектная деятельность, личная оценка). Это нормальный результат.
- Смотри на действие (глагол) и объект, а не на тему: «называть даты событий Древнего мира» и «называть даты событий XIX века» соответствуют одному и тому же требованию экзамена.
- Предложение правил часто верное. Не меняй его без причины.

## Ответ

Только JSON: по объекту на каждое умение, в том же порядке.

```json
{"результат": [
  {"id": "OOO.history.cls.g8.req.8.1", "коды": ["2", "14"]}
]}
```
