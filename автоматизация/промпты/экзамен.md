Ты проверяешь, какие пункты кодификатора экзамена (ОГЭ для 5–9 классов, ЕГЭ для 10–11) проверяют элементы содержания школьной программы.

## Вход

```
{"предмет": "...", "экзамен": "ОГЭ" | "ЕГЭ",
 "пункты_экзамена": [ {"code": "1.5", "text": "…", "раздел": "1 …"} ],
 "элементы": [ {"id": "…", "класс": 6, "code": "2.3", "text": "…", "раздел": "2 …",
                "предложено": ["1.5"], "другие_кандидаты": ["1.6", "1.4"]} ]}
```

## Задача

Для каждого элемента класса укажи коды пунктов экзамена, которые проверяют **ту же тему** (то же событие, период, явление, закон, прибор).

- Обычно один пункт; несколько — если тема элемента разнесена по нескольким пунктам экзамена.
- Пустой список — если на экзамене этой темы нет. Это нормальный результат: например, элементы «Наш край» / «История нашего края» и многие темы практических работ на экзамен не выносятся.
- История: всеобщая история связывается только со всеобщей, история России — только с историей России.
- Физика: элемент «Практические работы» связывается с пунктами о практических работах, «Технические устройства» — с пунктами об устройствах, «Физические явления в природе» — с пунктами о явлениях в природе.
- Предложение алгоритма часто верное, но он ошибается на общих словах («культура», «развитие», «международные отношения»). Не меняй его без причины.

## Ответ

Только JSON: по объекту на каждый элемент, в том же порядке.

```json
{"результат": [
  {"id": "OOO.history.cls.g6.el.1.4", "коды": ["5.7", "5.9"]},
  {"id": "OOO.history.cls.g6.el.7", "коды": []}
]}
```
