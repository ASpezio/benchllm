# ИС ОЗЯМ-ФОП · часть 4 · Бенчмарк

Задания для проверки моделей и «паспорт» модели.

План:
- **Задания из графа** — как семейства в K12-Bench: «что проверяет пункт экзамена», «что нужно знать до», «вид / часть», «какой опыт подтверждает».
- **Задания из шаблона требования** «действие + объект + рамка + сложность». Действие задаёт тип задания, рамка — материал, сложность — число шагов и степень самостоятельности.
- **Вес задания** — доля учебного времени понятия или элемента.
- **Паспорт модели** — результат по классам, разделам, типам понятий и действиям: «факты знает, сравнивать не умеет».

Статус: план.
