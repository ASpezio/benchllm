# Сборка навигатора с физикой

1. `../theme_pages.json` — страницы строк тематического планирования в PDF Конструктора.
2. `integrate.py <папка физика_поурочное>` — берёт `data.json` (данные из `navigator/index_до_физики.html`) и встраивает уроки, темы ФРП, веса элементов и часы пунктов ОГЭ/ЕГЭ → `data_new.json`.
3. `patch.py`, затем `patch2.py` — собирают `index.html`: несколько PDF (приказ + две выгрузки Конструктора), карточки уроков/тем физики, вкладка «Связи» для физики «по урокам», поиск места в ячейках таблиц Конструктора.
