# ИС ОЗЯМ-ФОП

Проект ВКР. Система проверяет, насколько языковая модель соответствует федеральной образовательной программе — тому, что выпускник должен знать и уметь, — по сути выдаёт модели «аттестат»: он подтверждает соответствие нормативу, а не средний уровень реальных учеников. Предметы: история и физика, 5–11 классы.

Основа — федеральная образовательная программа (ФОП, проект приказа Минпросвещения): что ученик должен знать, что уметь, сколько времени на это отводится и что проверяется на ОГЭ/ЕГЭ. Сама программа — оглавление без знаний, поэтому проект идёт так: размечаем программу → строим граф → наполняем граф знаниями из источников → делаем задания и проверяем модели.

**Главная идея:** во главе стоит не мнение экспертов, а нормативная рамка — государственная программа. Из неё строится семантический граф, а из графа — отбор знаний, вопросы и данные для дообучения. Поэтому система не только ставит рейтинг моделям, но и показывает, в каких областях им тяжелее всего, и может проверять саму программу и учебные материалы. Метод переносится на любую область, где есть нормативный документ. Подробно — **`КОНЦЕПЦИЯ.md`** (читать первым).

## Части

| № | Часть | Что внутри | Статус |
|---|---|---|---|
| 1 | **Разметка** (`1_разметка/`) | Приказ размечен построчно: уроки, элементы содержания, умения, кодификаторы ОГЭ/ЕГЭ; связи урок → элемент → экзамен, умение → требование экзамена; веса по часам; поурочный план физики из Конструктора edsoo (базовый + недостающее из углублённого); формулы через MinerU. Главное — `СВОДКА.md` и `ИДЕЯ — спецификация среднего ученика.md`. | готово |
| 2 | **Граф** (`2_граф/`) | Каркас из разметки + слой понятий (элемент → отдельные понятия с цитатой-основанием) + связи между понятиями («нужно знать до», «вид», «часть», «участник», «опыт подтверждает»). Просмотр — `2_граф/просмотр/`. | каркас готов; понятия и связи — пилот (история 5 кл., физика 7–8 кл.) |
| 3 | **Знания** (`3_знания/`) | Наполнение узлов-понятий содержанием из источников школьного уровня («Библиотека ЦОК» Минпросвещения, кодификатор ОГЭ) с дословной цитатой-подтверждением. | пилот: физика 7 кл. — 149 понятий, 236 знаний |
| 4 | **Бенчмарк** (`4_бенчмарк/`) | Задания из графа и шаблонов требований («действие + объект + рамка + сложность»), прогон моделей, «паспорт» модели по классам, разделам и действиям. | пилот: физика 7 кл. — 839 заданий; прогон моделей — дальше |

## Папки

- `источники/` — PDF: проект приказа, рабочие программы по физике из Конструктора edsoo (базовый и углублённый уровень).
- `navigator/` — навигатор по приказу (запуск: **«Открыть навигатор.command»**).
- `2_граф/просмотр/` — просмотр графа понятий (запуск: **«Открыть граф.command»**).
- `автоматизация/` — части 1–4 одной командой с локальной LLM вместо ручных решений: разметка и граф по PDF приказа, знания и задания по срезу «предмет + класс» (`автоматизация/README.md`).

Оба запускаются двойным щелчком: поднимается локальный сервер, страница открывается в браузере. Чтобы остановить, закройте окно Терминала.
